# 雲端硬碟同步：部署步驟

`drive-sync.gs` 會在指定的雲端硬碟資料夾（`ROOT_FOLDER_ID`，目前是「記帳本網路硬碟」）裡建立：

```
記帳本網路硬碟/
├── 使用者A/
│   ├── data.json     ← 所有資料（記帳、投資、預算、設定……）
│   └── 圖片/          ← 分類圖示、背景圖等圖片
└── 使用者B/
    ├── data.json
    └── 圖片/
```

## 1. 建立 Apps Script 專案

1. 打開 <https://script.google.com>，按「新專案」。
2. 把預設的 `程式碼.gs` 內容全部刪掉，貼上 `drive-sync.gs` 的內容，存檔。
3. 專案名稱可改成「記帳本雲端硬碟同步」。

> 請建立**新的**專案，不要貼進原本 Google Sheet 備份用的專案（兩者都用 `doPost`，會互相衝突）。

## 2. 部署成網頁應用程式

1. 右上角「部署」→「新增部署作業」→ 類型選「網頁應用程式」。
2. 執行身分：**我**
3. 誰可以存取：**所有人**
4. 按「部署」，第一次會要求授權雲端硬碟權限，按允許。
5. 複製「網頁應用程式網址」（結尾是 `/exec`）。

## 3. 在記帳本裡設定

1. 設定 → 👤 雲端硬碟帳號 → 🔗 雲端硬碟網址，貼上剛剛的網址。
2. 按「登入 / 註冊」，輸入帳號密碼，按「註冊新帳號」。
3. 註冊完成會自動在雲端硬碟建立該使用者的資料夾，並上傳所有資料。

每台裝置都要設定一次網址。之後在其他裝置登入同一個帳號，會詢問要下載雲端資料，還是上傳這台裝置的資料。

## 自動同步

登入後不需要手動上傳：

- 資料一有變動，約 3 秒後自動上傳（畫面下方會短暫顯示「☁️ 已同步」）。
- 每 60 秒、以及切回記帳本頁面時，會檢查雲端有沒有其他裝置的新資料，有的話自動下載並重新整理。正在輸入時會等輸入完再更新。
- 兩台裝置都改了資料時，會詢問要保留雲端的版本，還是用這台裝置的資料覆蓋雲端。
- 離線時的變更會先記著，下次連上網路或打開記帳本時再上傳。
- 股價這類自動更新的資料不會觸發上傳（但上傳時會一起帶上）。

## 連不上時（瀏覽器出現 CORS 錯誤、403 Forbidden）

這代表 Google 拒絕了請求，幾乎都是部署的存取權限不對：

1. Apps Script 右上角「部署」→「管理部署作業」→ 點鉛筆圖示編輯。
2. 「誰可以存取」改成**所有人**（不是「僅限自己」，也不是「擁有 Google 帳戶的任何使用者」）。
3. 「版本」選「新版本」→ 按「部署」。網址不會變。

確認方式：用無痕視窗直接打開網址，應該看到
`{"ok":true,"service":"記帳本雲端硬碟同步","version":1}`；
看到「存取遭拒」或要求登入，就是權限還沒改好。

## 注意事項

- 所有使用者的資料都存在**部署者**的雲端硬碟，部署者看得到每個人的資料夾。
- 資料夾**不需要**對外分享，程式是用部署者的身分存取。請把「一般存取權」設為「限制」，否則任何拿到連結的人都能看到所有人的記帳資料。
- 密碼只存加鹽雜湊值，不會存明碼；帳號與登入狀態存在 Apps Script 的「指令碼屬性」。
- 登入狀態 30 天有效，過期需重新登入。
- 上傳時，資料裡已經沒用到的圖片會移到雲端硬碟的垃圾桶（30 天內可救回）。
- 修改 `drive-sync.gs` 後要「部署 → 管理部署作業 → 編輯 → 版本：新版本」才會生效，網址不變。
